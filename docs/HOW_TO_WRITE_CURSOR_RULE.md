# How to Make a Cursor Rule (`.mdc`)

Every rule in `.cursor/rules/*.mdc` **must start** with YAML frontmatter delimited by `---` lines, followed by the rule body.

## Required frontmatter schema
```yaml
---
rule_id: "<file name without .mdc>"
title: "Short human title"
phase: "9.5.7.4.6"          # tie rule to project phase (or current)
applies: "always"           # always | phase | optional
enforcement: "strict"       # strict | advisory
owner: "researcher-ssot"    # code owner
updated: "YYYY-MM-DD"       # ISO date
version: 1                  # increment on substantive changes
scope: "all"                # or a list of globs, e.g. ["src/**", "scripts/**"]
summary: "What this rule enforces and why"
links: []                   # optional references
checksum: "<auto>"          # sha256 of the body (auto-generated by fixer)
---
<rule body in Markdown>
```

## Special case: `00-global.mdc`
- `applies` must be `always`
- `enforcement` must be `strict`
- `scope` should be `all` (or `["**/*"]`)

## Commands
```bash
# Validate (fails CI on error)
make rules-validate

# Auto-fix missing/partial frontmatter (then validate)
make rules-fix

# Enable pre-commit hook so malformed rules never land
make enable-githooks
```

The **checksum** binds the rule body to the frontmatter. Any edit to the body changes the checksum; run `make rules-fix` to refresh it.
